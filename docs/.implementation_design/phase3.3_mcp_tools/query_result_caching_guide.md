## Cache Types and Persistence

### In-Memory Cache (Session-Based)

**Characteristics:**
- Data stored in RAM
- Fastest access (sub-millisecond)
- **Does NOT persist across application restarts**
- Limited by available memory
- Suitable for development and testing

**Use Cases:**
- Development environments
- Single-user applications
- Temporary caching during session

**Limitations:**
- Data lost on application restart
- Memory consumption grows over time
- Not suitable for production multi-instance deployments

### File-Based Cache (Persistent)

**Characteristics:**
- Data stored in files (pickle, JSON)
- Persists across application restarts
- Slower than in-memory but faster than database
- Limited by disk space

**Use Cases:**
- Single-instance production deployments
- Applications with moderate cache requirements
- Development environments requiring persistence

### SQLite Cache (Persistent Database)

**Characteristics:**
- Lightweight database storage
- Persists across application restarts
- ACID compliance
- Built-in expiration and cleanup
- Suitable for small to medium applications

**Use Cases:**
- Single-instance applications
- Applications requiring data integrity
- Development and testing environments

### Redis Cache (Distributed Persistent)

**Characteristics:**
- High-performance in-memory database
- Persists across application restarts
- Supports clustering and high availability
- Sub-millisecond response times
- Production-ready with monitoring

**Use Cases:**
- Production multi-instance deployments
- High-traffic applications
- Distributed systems
- Applications requiring high availability

## Cache Key Generation

### Purpose

The cache key is a unique identifier that determines whether a query result has been cached before. It's generated by combining all parameters that affect the retrieval result.

### Generation Process

```python
def _generate_cache_key(self, query: str, collection_id: str, **params) -> str:
    """Generate namespaced cache key"""
    # Sort parameters for consistent key generation
    sorted_params = sorted(params.items())
    param_str = "&".join([f"{k}={v}" for k, v in sorted_params])
    
    # Create hash of query + collection + parameters
    key_data = f"{query}|{collection_id}|{param_str}"
    key_hash = hashlib.md5(key_data.encode()).hexdigest()
    
    # Return namespaced key
    return f"{self.namespace}:query:{key_hash}"
```

### Cache Key Components

1. **Namespace**: Application-specific prefix (e.g., `agenthub_doc_retrieval`)
2. **Key Type**: Category of cached data (e.g., `query`, `collection`, `stats`)
3. **MD5 Hash**: 32-character hexadecimal string representing the unique combination

### Redis Cache Manager Implementation

```python
import redis
import json
import asyncio
import hashlib
import logging
from typing import Optional, Dict, Any, List
from datetime import datetime, timedelta
import os

class RedisCacheManager:
    """Production-ready Redis cache manager for document retrieval"""
    
    def __init__(self, redis_url: str = None, namespace: str = "doc_retrieval"):
        # Get Redis URL from environment or use default
        self.redis_url = redis_url or os.getenv("REDIS_URL", "redis://localhost:6379")
        self.namespace = namespace
        self.logger = logging.getLogger(__name__)
        
        # Initialize Redis connection with connection pooling
        self.redis_client = redis.from_url(
            self.redis_url,
            decode_responses=True,
            socket_connect_timeout=5,
            socket_timeout=5,
            retry_on_timeout=True,
            health_check_interval=30
        )
        
        # Test connection
        self._test_connection()
        
        # Cache statistics
        self.hit_count = 0
        self.miss_count = 0
    
    def _test_connection(self):
        """Test Redis connection and log status"""
        try:
            self.redis_client.ping()
            self.logger.info(f"✅ Redis connection successful: {self.redis_url}")
        except Exception as e:
            self.logger.error(f"❌ Redis connection failed: {e}")
            raise ConnectionError(f"Failed to connect to Redis: {e}")
    
    def _generate_cache_key(self, query: str, collection_id: str, **params) -> str:
        """Generate namespaced cache key"""
        # Sort parameters for consistent key generation
        sorted_params = sorted(params.items())
        param_str = "&".join([f"{k}={v}" for k, v in sorted_params])
        
        # Create hash of query + collection + parameters
        key_data = f"{query}|{collection_id}|{param_str}"
        key_hash = hashlib.md5(key_data.encode()).hexdigest()
        
        # Return namespaced key
        return f"{self.namespace}:query:{key_hash}"
    
    async def get(self, cache_key: str) -> Optional[Dict[str, Any]]:
        """Retrieve cached result"""
        try:
            data = self.redis_client.get(cache_key)
            if data:
                self.hit_count += 1
                self.logger.debug(f"🎯 Cache HIT: {cache_key}")
                return json.loads(data)
            
            self.miss_count += 1
            self.logger.debug(f"❌ Cache MISS: {cache_key}")
            return None
            
        except Exception as e:
            self.logger.error(f"❌ Redis get error: {e}")
            self.miss_count += 1
            return None
    
    async def set(self, cache_key: str, data: Dict[str, Any], ttl: int = 3600) -> None:
        """Store result in cache with TTL"""
        try:
            # Serialize data to JSON
            json_data = json.dumps(data, default=str)
            
            # Store with TTL
            self.redis_client.setex(cache_key, ttl, json_data)
            
            self.logger.debug(f"💾 Cached: {cache_key} (TTL: {ttl}s)")
            
        except Exception as e:
            self.logger.error(f"❌ Redis set error: {e}")
    
    async def invalidate_collection(self, collection_id: str) -> None:
        """Invalidate all cached results for a collection"""
        try:
            # Use pattern matching to find all keys for this collection
            pattern = f"{self.namespace}:query:*"
            keys = self.redis_client.keys(pattern)
            
            # Filter keys that contain the collection_id
            collection_keys = []
            for key in keys:
                # Get the original data to check collection_id
                data = self.redis_client.get(key)
                if data:
                    try:
                        parsed_data = json.loads(data)
                        if parsed_data.get('collection_id') == collection_id:
                            collection_keys.append(key)
                    except:
                        continue
            
            # Delete matching keys
            if collection_keys:
                self.redis_client.delete(*collection_keys)
                self.logger.info(f"🗑️ Invalidated {len(collection_keys)} cache entries for collection: {collection_id}")
            
        except Exception as e:
            self.logger.error(f"❌ Redis invalidation error: {e}")
    
    async def clear_all(self) -> None:
        """Clear all cache entries for this namespace"""
        try:
            pattern = f"{self.namespace}:*"
            keys = self.redis_client.keys(pattern)
            if keys:
                self.redis_client.delete(*keys)
                self.logger.info(f"🧹 Cleared {len(keys)} cache entries")
        except Exception as e:
            self.logger.error(f"❌ Redis clear error: {e}")
    
    def get_stats(self) -> Dict[str, Any]:
        """Get comprehensive cache statistics"""
        try:
            redis_info = self.redis_client.info()
            total_requests = self.hit_count + self.miss_count
            hit_rate = (self.hit_count / total_requests * 100) if total_requests > 0 else 0
            
            # Count our namespace keys
            pattern = f"{self.namespace}:*"
            our_keys = self.redis_client.keys(pattern)
            
            return {
                "cache_type": "Redis",
                "redis_url": self.redis_url.replace(self.redis_url.split('@')[0].split('://')[1], "***"),  # Hide password
                "namespace": self.namespace,
                "our_cache_size": len(our_keys),
                "hit_count": self.hit_count,
                "miss_count": self.miss_count,
                "hit_rate": f"{hit_rate:.2f}%",
                "total_requests": total_requests,
                "redis_memory_used": redis_info.get("used_memory_human", "Unknown"),
                "redis_connected_clients": redis_info.get("connected_clients", 0),
                "redis_version": redis_info.get("redis_version", "Unknown")
            }
        except Exception as e:
            return {"error": str(e)}
    
    async def health_check(self) -> bool:
        """Check Redis health"""
        try:
            self.redis_client.ping()
            return True
        except:
            return False
```

### Enhanced DocumentRetrievalEngine with Redis

```python
# document_retrieval_engine.py
class DocumentRetrievalEngine:
    """Main retrieval engine with Redis caching"""
    
    def __init__(self, collection_manager: CollectionManager, cache_manager: RedisCacheManager = None):
        self.collection_manager = collection_manager
        self.cache_manager = cache_manager
        self.synthesis_llm = self._setup_synthesis_llm()
        self.rerank_llm = self._setup_rerank_llm()
        self.request_timeout_sec = 20
        
        # Cache configuration
        self.cache_config = {
            "chunks": {"ttl": 3600, "enabled": True},      # 1 hour
            "answer": {"ttl": 1800, "enabled": True},      # 30 minutes
            "reranked": {"ttl": 7200, "enabled": True},    # 2 hours
        }
    
    async def retrieve(
        self, 
        query: str, 
        collection_id: str, 
        top_k: int = 5,
        return_format: str = "chunks",
        similarity_threshold: float = 0.7,
        enable_reranking: bool = True,
        **kwargs
    ) -> dict:
        """Main retrieval method with Redis caching"""
        
        # Check if caching is enabled for this format
        cache_config = self.cache_config.get(return_format, {})
        if not cache_config.get("enabled", False) or not self.cache_manager:
            # Perform retrieval without caching
            return await self._perform_retrieval(
                query, collection_id, top_k, return_format, 
                similarity_threshold, enable_reranking, **kwargs
            )
        
        # Generate cache key
        cache_key = self.cache_manager._generate_cache_key(
            query=query,
            collection_id=collection_id,
            top_k=top_k,
            return_format=return_format,
            similarity_threshold=similarity_threshold,
            enable_reranking=enable_reranking,
            **kwargs
        )
        
        # Try to get from cache first
        cached_result = await self.cache_manager.get(cache_key)
        if cached_result:
            # Add cache metadata
            cached_result["cache_metadata"] = {
                "cached": True,
                "cache_hit": True,
                "cache_key": cache_key
            }
            return cached_result
        
        # Perform actual retrieval
        result = await self._perform_retrieval(
            query, collection_id, top_k, return_format, 
            similarity_threshold, enable_reranking, **kwargs
        )
        
        # Add cache metadata
        result["cache_metadata"] = {
            "cached": True,
            "cache_hit": False,
            "cache_key": cache_key
        }
        
        # Cache the result
        ttl = cache_config.get("ttl", 3600)
        await self.cache_manager.set(cache_key, result, ttl=ttl)
        
        return result
```

## Best Practices

### 1. Cache Key Design

- **Use deterministic keys**: Same input should always produce the same key
- **Include all relevant parameters**: Any parameter that affects the result should be in the key
- **Use namespaces**: Prevent conflicts between different applications or environments
- **Keep keys readable**: Include meaningful prefixes for debugging

### 2. TTL Configuration

- **Chunks**: 1-2 hours (raw data, changes infrequently)
- **Answers**: 30 minutes (synthesized content, may change with LLM updates)
- **Reranked results**: 2-4 hours (expensive to compute, stable for longer)

### 3. Error Handling

- **Graceful degradation**: Always fall back to non-cached retrieval if cache fails
- **Connection retry**: Implement retry logic for Redis connection failures
- **Timeout management**: Set appropriate timeouts for cache operations
- **Logging**: Log cache hits, misses, and errors for monitoring

### 4. Performance Optimization

- **Connection pooling**: Use Redis connection pooling for better performance
- **Batch operations**: Use Redis pipeline for multiple operations
- **Memory management**: Monitor Redis memory usage and set appropriate limits
- **Key expiration**: Use TTL to automatically clean up old cache entries

### 5. Security Considerations

- **Authentication**: Use Redis AUTH for production deployments
- **Network security**: Use TLS for Redis connections in production
- **Access control**: Limit Redis access to authorized applications only
- **Data encryption**: Consider encrypting sensitive cached data

### 6. Monitoring and Alerting

- **Cache hit rate**: Monitor and alert on low hit rates
- **Memory usage**: Alert on high Redis memory usage
- **Response times**: Monitor cache operation response times
- **Error rates**: Track and alert on cache operation failures

### 7. Development vs Production

- **Development**: Use local Redis or in-memory cache for simplicity
- **Testing**: Use separate Redis instances for different test environments
- **Production**: Use Redis Cluster or cloud Redis for high availability
- **Staging**: Use production-like Redis setup for accurate testing

## Conclusion

Query result caching is a critical component for improving the performance and user experience of the document retrieval tool. By implementing Redis-based caching with proper key generation, TTL management, and monitoring, you can achieve significant performance improvements while maintaining data consistency and reliability.

The key is to choose the right caching strategy for your use case, implement proper error handling and monitoring, and follow best practices for security and performance optimization.
